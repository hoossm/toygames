ToyGames — Local Arabic Store v0.1

Run:
1) Install Node.js 18+.
2) Open PowerShell in this folder.
3) npm install
4) npm run dev
5) Open http://localhost:5173

This first version is a lightweight RTL storefront using your supplied ToyGames logos,
#ff6205, #ffa909, white and #181818. It is responsive for mobile and desktop.
The game data is demo data for now. Steam CDN images are referenced, not stored locally.

Next: connect SQLite, import the real Steam catalog, connect the safe price worker,
then add game pages, accounts, cart, checkout and admin tools.
